Do I really need zero npm packages to run the MCP servers and security hooks?

Yes. Every MCP server and guardrail hook runs directly on native Node.js 18+/22 standard modules (node:fs, node:crypto, node:dns, node:sqlite). There is no npm install, no lockfile bloat, and you can inspect every line of code in minutes.

Which AI coding tools are supported out of the box?

Claude Code (.claude/settings.json hooks + MCP), Cursor (.cursor/rules/*.mdc + MCP), Windsurf, Antigravity, and any MCP-compatible stdio client. The n8n workflows run on any standard self-hosted or cloud n8n instance.

Yes — all 3 products have live, MIT-licensed Lite editions on GitHub (ai-agent-guardrails-lite, mcp-starter-suite-lite, and ai-automation-vault-lite). Clone them, run the tests locally, and only upgrade to Pro when you want the full libraries.
